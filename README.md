# Portfolio — Idriss Elba Kapata

Portfolio personnel d’Idriss Elba Kapata, développeur Web Full Stack. Le site présente des applications métier, des tableaux de bord et des interfaces responsives développés avec React, Laravel, PHP, MySQL et JavaScript.

## Fonctionnalités

Le portfolio comprend une présentation professionnelle, une sélection de projets, une section de compétences techniques, des services, des liens GitHub et LinkedIn ainsi qu’un formulaire de contact avec choix entre email et WhatsApp. Les cartes projet sont navigables au clavier et les métadonnées SEO sont incluses dans la page HTML.

## Technologies

- React 19
- Vite
- JavaScript moderne
- CSS responsive
- React Icons
- GitHub Pages via GitHub Actions

## Installation locale

```bash
npm install
npm run dev
```

Pour vérifier la version de production :

```bash
npm run build
npm run preview
```

## Déploiement

Le workflow `.github/workflows/deploy-pages.yml` construit automatiquement le site et le publie sur GitHub Pages après chaque push sur `master`. Dans les paramètres du dépôt GitHub, la source Pages doit être configurée sur **GitHub Actions**.
